# 한붓그리기 (One Stroke)

점과 점을 잇는 선을 **한 번도 떼지 않고, 같은 선을 두 번 지나지 않게** 모두 그으면 완성되는 퍼즐 게임입니다.
5단계 × 5문제, 모두 25개의 문제가 들어 있어요.

**바로 하기:** https://chohanui2-home.github.io/one-stroke/

## 게임 방식

- 같은 선을 두 번 지나지 않고, 한 번에 모든 선을 이어 보세요. (연필을 떼면 끝!)
- 점을 **차례로 눌러도** 되고, 점에서 시작해 **손가락으로 쭉 끌어도** 됩니다. 끌고 있는 동안에는 지금 점에서 손가락까지 미리보기 선이 보여요.
- 단계 탭에서 1–5단계를 자유롭게 오가고, 단계 안의 5문제도 원하는 것부터 골라서 풀 수 있어요. 꼭 순서대로 하거나 5개를 다 끝내지 않아도 됩니다. 이번에 연 화면에서 마친 문제에는 은은한 ✓ 표시가 붙어요.
- **완성하면 다음 문제로 자동 이동** 마지막 선을 이으면 "완성! 모든 선을 한 번에 이었어요."와 ✓를 약 0.5초 보여 준 뒤 같은 단계의 다음 문제로 넘어가요. 그 단계의 5번 문제를 마치면 다음 단계 첫 문제로 넘어갑니다. 넘어가기 전에 다른 문제·단계를 누르거나 **처음부터**·**되돌리기**를 누르면 자동 이동은 취소돼요. 마지막 문제(5-5)는 완성 화면 그대로 머물러요.
- **되돌리기** 마지막에 그은 선 하나를 취소해요. (출발점만 찍힌 상태에서는 출발점을 해제)
- **처음부터** 지금 문제를 처음 상태로 돌려요.
- **힌트 보기** 지금 상태에서 끝까지 그을 수 있는 길을 계산해 출발점(시작 전) 또는 다음 1–2수를 점선과 화살표로 보여 줘요. 이미 막힌 길이면 "지금 길은 끝까지 갈 수 없어요! '되돌리기'로 한두 칸 돌아가 보세요."라고 알려 줍니다.
- 점수·타이머·별점 같은 것은 없어요. 천천히 생각하면서 그리면 됩니다.

## 공용 태블릿(학교 행사)에서 쓰기

여러 아이가 한 태블릿을 번갈아 써도 앞사람 흔적이 남지 않아요.

- **문제를 옮기면 언제나 빈 판** — 다른 문제로 가거나, 단계 탭을 누르거나, 이미 푼 문제를 다시 눌러도 항상 0선의 깨끗한 판으로 열립니다.
- **단계 탭은 늘 그 단계 1번 문제부터** — 앞사람이 1–4까지 풀었어도 1번 문제가 열립니다.
- **기록을 기기에 저장하지 않아요** — 마친 문제의 ✓는 지금 화면에서만 보이고, 링크를 다시 열거나 새로고침하면 사라집니다. localStorage에 아무것도 쓰지 않습니다.
- 다음 아이는 문제를 누르거나 링크를 다시 열면 바로 새 판에서 시작해요.

## 5단계 25문제

| 단계 | 이름 | 문제 |
|---|---|---|
| 1 | 입문 | 나비 · 이층집 · 왕관 · 산 · 겹친 사각 (7–8선) |
| 2 | 초급 | 삼각 격자 · 벌집 · 육각 별 윤곽 · 우산 · 여섯 별 (10–12선) |
| 3 | 중급 | 3×3 격자 · 팔각 대칭 · 바람개비 · 일곱 별 · 겹친 육각 (13–16선) |
| 4 | 도전 | 확장 격자 · 아홉 별 · 삼각 그물 · 육각별 복합 · 오각 별 두 겹 (17–20선) |
| 5 | 고수 | 칠각형 완전 연결 · 쌍둥이 별과 다리 · 육각별 테두리 · 팔각 거미줄 · 복합 격자 (21–26선) |

단계가 올라갈수록 점과 선이 빠르게 늘어나요. 1단계는 7–8선, 5단계는 21–26선(칠각형 완전 연결 21선, 팔각 거미줄 24선, 복합 격자 23선 등)으로, 어른도 한참 고민해야 풀립니다.

25문제 모두 **홀수점이 0개 또는 2개**이고 **하나로 이어진 도형**이라, 반드시 한붓그리기로 완성할 수 있어요.
점 사이 간격과 선-점 거리도 모두 검사해, 손가락으로 짚기 좋고 선이 다른 점을 스쳐 지나가지 않게 만들었습니다.
(자세한 조건은 게임 아래 "한붓그리기가 되는 조건" 카드에 적어 두었습니다.)

## 특징

- **회색톤 디자인** — 연한 모눈종이 판에 흰 점·회색 선. 눈이 편하고 도형이 또렷하게 보여요.
- **모바일·태블릿 최적화** — 아이폰 안전 영역 여백, 손가락 터치 반경을 넉넉하게, 가로 넘침 없이 한 손 조작.
- **기록을 남기지 않아요** — 문제·단계를 옮길 때마다 빈 판으로 새로 시작하고, 마친 문제 표시(✓)도 화면을 새로 열면 사라집니다. 점수나 기록은 어디에도 저장하지 않습니다.
- **외부 리소스 0건** — 폰트·CDN·이미지·오디오를 하나도 불러오지 않는 단일 HTML. 파일 하나만 보내도 오프라인에서 그대로 열립니다.

## 파일

- `index.html` — 게임 전체가 들어 있는 단일 파일 (외부 요청 0건)
- `app_template.html` — 빌드용 템플릿 (`__PUZZLES__` 자리표시자 포함)
- `puzzles.json` — 25문제의 점 좌표와 선 목록 (설계 원본)
- `gen_puzzles.py` — 25문제를 도형 부품으로 조립하고 이어진 도형·홀수점 0/2·선이 점을 지나지 않음·점 간격·오일러 경로·중복 그래프 없음을 검사해 `puzzles.json`을 씁니다 (`--write`)
- `build.py` — 퍼즐 주입·단일 파일 규칙·단계별 선 수(7–8 / 10–12 / 13–16 / 17–20 / 21–26) 검사 후 `index.html`과 `dashboards/한붓그리기.html`에 같은 바이트로 기록
- `test_app.py` — 정적 규칙 + 25문제 수학 검증(연결성·홀수점·겹침·오일러 경로) + QuickJS로 실제 스크립트를 돌려 탭·드래그·되돌리기·힌트·단계 이동·완성 후 자동 넘김(대기 시간·단계 경계·타이머 취소)·문제 이동 시 빈 판·localStorage 미사용을 검사하는 자동 테스트

## 다시 빌드하기

```bash
python3 build.py      # index.html + dashboards/한붓그리기.html 생성
python3 test_app.py   # 자동 테스트
```
